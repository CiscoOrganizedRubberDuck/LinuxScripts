# LinuxScripts
**Features** 
- Adds and Removes Users 
- Adds and Removes Admins
- Changes all user passwords to "CyberPartriot2025!"  
- Enables UFW 

**How to use?**
- Create a text file in the same directory as the script called "Users.txt" and store proper users in the file 
- Create a text file in the same directory as the script called "Admins.txt" and store proper users in the file 
- Run the Script w/ SUDO or root: sudo ./main.sh 
- Logs will be stored in a seperate file
