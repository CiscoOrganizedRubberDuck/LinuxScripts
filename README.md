# LinuxScript v0.45
**Features** 
- Adds and Removes Users 
- Adds and Removes Admins
- Changes all user passwords 
- Enables UFW 
- Logs will be stored in a seperate file
- Ability to add and remove packages
- Unrefined Auditing 

**How to use?**
- Copy and Paste the whole admins and users box into Input.txt 
- Run the Script w/ SUDO or root: sudo ./main.sh 
- Relax for a bit and then read the logs after find extra files
